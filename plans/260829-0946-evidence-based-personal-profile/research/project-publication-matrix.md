# Project publication matrix

Status: working draft for Phase 2  
Updated: 2026-08-29

## Rules

- **Public:** project name and public source/site may be shown; every claim and asset still needs a final safety check.
- **Anonymized:** describe the system, role, constraint, and lesson without client/company name, logo, private URL, proprietary screen, or metric.
- **Private:** no public node until Đức explicitly changes the decision.
- Team projects must use exact contribution language. Commit authorship is evidence of contribution, not proof of sole ownership.
- No README-stated metric ships without independent publishable proof.
